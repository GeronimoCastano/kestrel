# Kestrel logo

The selected mascot has spread wings, a chestnut and cream body, and rectangular eyes.

## Choosing a file

| File | Use |
| --- | --- |
| `kestrel-original.png` | The exact approved artwork, unchanged, at 1254 × 1254 pixels. Keep this as the original. |
| `png/kestrel-512.png` | Documentation, repository avatars, and everyday web use. |
| `png/kestrel-1024.png` | Larger displays and presentations. |
| `png/kestrel-32.png` through `png/kestrel-256.png` | Small icons at their intended display size. |
| `png/kestrel-2048.png` and `png/kestrel-4096.png` | Enlarged PNG copies with nearest-neighbor scaling to preserve the pixel edges. These contain no additional source detail. |
| `kestrel.svg` | A scalable vector tracing for large layouts, print, or further editing. Its shapes are real vector paths. Tracing slightly simplifies the original shading and edges; use the PNG when you want the exact approved appearance. |
| `favicon.ico` | Browser icon with 16, 32, 48, 64, 128, and 256 pixel versions. |
| `preview.png` | A preview on light and dark backgrounds, including icons shown at their actual sizes. |

All logo PNGs and the SVG have transparent backgrounds. The preview includes its own backgrounds.

Keep the logo square and preserve its proportions. Check the face and wing tips at the intended display size, especially below 64 pixels.
